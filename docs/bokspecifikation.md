# Bokspecifikation

## Titel
Arbetstitel: Java 25 för Java 21-utvecklare

## Språk
Svenska, med engelska i källkodsexempel, API-namn och etablerade Java-begrepp där svensk motsvarighet saknas eller blir onaturlig.

## Ämne
Boken lär ut vad erfarna Java-utvecklare behöver förstå, värdera och praktiskt använda när de går från Java 21 till Java 25.

## Syfte
Efter boken ska läsaren kunna:
- identifiera relevanta nyheter mellan Java 21 och Java 25,
- bedöma vilka features som är produktionsmogna, preview eller incubating,
- skriva och granska kod som använder centrala språk- och biblioteksnyheter,
- planera migration från Java 21 till Java 25 i professionella system,
- resonera om prestanda, observability, säkerhet och kompatibilitet.

## Målgrupp
Erfarna systemutvecklare som redan kan Java 21 och arbetar med backend, plattform, bibliotek, arkitektur eller modernisering av Java-system.

## Förkunskaper
Läsaren antas kunna:
- Java 21 på praktisk nivå,
- records, pattern matching, switch expressions, virtual threads och grundläggande concurrency,
- Maven eller Gradle,
- testning och byggflöden i professionella Java-projekt,
- grundläggande JVM-begrepp.

## Svårighetsgrad
Erfaren, med vissa avancerade avsnitt. Boken förklarar nya features men repeterar inte Java-grunder.

## Boktyp
Praktisk lärobok/handbok.

## Pedagogisk stil
Jämförande och praktisk: från Java 21-baslinje till Java 25, med små körbara exempel, migreringsråd, tradeoffs och tydliga markeringar för final, preview, incubating och experimental.

## Omfattning
Medel: cirka 12 kapitel.

## Avgränsningar
Boken ska inte vara en komplett introduktion till Java, JVM eller enterprise-arkitektur. Den ska inte täcka alla implementationers supportvillkor i detalj, utan hänvisa till respektive JDK-distributör där uppgiften är leverantörsspecifik.

## Återkommande exempel eller projekt
Ett fiktivt ordersystem, `OrderFlow`, används som återkommande exempel för API-design, concurrency, observability, säkerhet och prestanda.

## Ton och stil
Professionell, tydlig och pragmatisk. Läsaren behandlas som erfaren kollega, inte som nybörjare.
