# Java 25 för Java 21-utvecklare

Detta är projektmappen för en svensk lärobok/handbok om att gå från Java 21 till Java 25.

## Struktur

- `docs/` innehåller bokspecifikation, kapitelplan, canon, terminologi, status och exportmetadata.
- `chapters/` innehåller inledning och kapitelutkast.
- `exercises/` innehåller separata övningsfiler vid behov.
- `examples/` innehåller scenarier och icke-kodexempel.
- `code/` innehåller körbara kodexempel när kapitel skapas.
- `assets/` innehåller bilder, diagram och exportresurser.
- `exports/` innehåller genererade exportfiler.

## Nästa steg

1. Granska bokspecifikation och kapitelplan.
2. Skapa nästa kapitel enligt kapitelplanen.
3. Uppdatera canon, terminologi och projektstatus efter varje kapitel.
